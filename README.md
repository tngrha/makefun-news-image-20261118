A Python program (stdlib + PIL only) that draws a 1024x1024 newspaper front page summing up the world news of Wednesday 18 November 2026 and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`. Masthead names the day; hero: Nvidia's earnings — revenue $115.84bn, doubled year on year, board will not reinstate Jensen Huang; eight story tiles cover the Manila ASEAN talks, the Crimean Bridge strikes, the Iran drone attack in Bahrain, Canada–China trade, UK settlement sanctions, the UN casualty tolls, Dhoni's IPL retirement, and Deutsche Bank; footer "Also in brief": Cyclone Akvan, SpaceX, the Grammys, and Trump's BBC lawsuit deadline. Deterministic, no network, no randomness — repeated runs are byte-identical.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
